NaturalWrite 0.1.0 — development preview

Download an app from **Assets** below; the automatic “Source code” ZIP is for developers.

- **Mac with Apple silicon (M-series):** choose the macOS arm64 DMG or ZIP.
- **Intel Mac:** choose the macOS x64 DMG or ZIP.
- **Windows 10/11 x64:** choose the Windows Setup EXE.

On Mac, open the DMG and drag NaturalWrite into Applications, or extract the ZIP. Requires macOS 12 or newer. These previews are not Developer ID signed or Apple-notarized; macOS may require Privacy & Security → Open Anyway. Windows may display an unknown-publisher warning.

Includes local SQLite documents and writing profiles, sample imports, style observations, preservation controls, per-change review, consent-based feedback, and optional AI provider configuration. Offline proofreading is limited; broader AI revision needs your own provider account and API key.

This is a development preview. Automated core/storage/import/provider tests and production builds run before packaging. Native installation and operating-system key storage have not been manually tested. One additional Linux desktop settings workflow test previously timed out and remains unresolved. See VALIDATION.md for the testing limits. Meaning checks are fallible; review all suggested edits.
